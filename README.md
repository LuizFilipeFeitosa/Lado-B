  #   Lado B
  
Este repositório é dedicado à disciplina de Desenvolvimento de Sistemas de Informação (BSI/UFRPE). O **Side B** é um aplicativo mobile voltado ao registro, avaliação e análise crítica de produções musicais. A proposta estimula o debate sobre obras musicais e desenvolve uma comunidade colaborativa.
