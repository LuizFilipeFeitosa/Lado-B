  # Side B
  
Este repositório é dedicado à disciplina de Desenvolvimento de Sistemas de Informação (BSI/UFRPE). O **Side B** é um aplicativo mobile voltado ao registro, avaliação e análise crítica de produções musicais. A proposta estimula o debate sobre obras musicais e fortalece a difusão da cultura fonográfica ao documentar a produção artística de diferentes épocas e gêneros.
